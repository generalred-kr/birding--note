# 탐조 기록장

휴대폰에서 탐조 중에 눌러서 기록하고, 집에서 eBird에 올릴 수 있는 파일로 내보내는 웹 앱입니다. 서버나 로그인 없이 브라우저만 있으면 쓸 수 있습니다. 개인용으로 만든 비공식 도구이며 eBird, Cornell Lab of Ornithology와 관련이 없습니다.

## 기능

- **탐조 기록**: 날짜와 시각, 장소(직접 입력 가능), 탐조 방식(이동·정점·우연), 관찰자 수, 동행(자주 함께한 3명), 이동 거리, 모두 기록 여부. 날씨, 기온, 바람, 서식지, 물 상태, 장비, 방해 요인, 목적, 이동 수단, 메모는 "더보기"에 있습니다.
- **종 기록**: 한국 조류 598종을 이름, 초성(예: ㅈㅂ), 영문명, 학명, 과 이름으로 검색합니다. 개체수는 숫자로 직접 입력하고, 행동, 확실도, 소리만 들음, 확인 필요, 희귀 표시를 남깁니다. 저장 버튼은 창 아래에 고정되어 있습니다.
- **특징**: 새 그림에서 부위별 색(머리, 부리, 등, 배, 날개, 허리, 꼬리, 다리)과 무늬 12가지를 팔레트로 고릅니다. 그림을 누르면 확대됩니다.
- **eBird 링크**: 종마다 eBird 종 페이지로 가는 버튼이 있습니다.
- **내보내기**: eBird 가져오기용 CSV(레코드 형식)와 백업 파일.
- **자동 저장과 불러오기**: 1분마다, 그리고 기록을 바꿀 때마다 브라우저에 저장하고, 자동 저장본이나 백업 파일을 합치거나 바꿔서 불러올 수 있습니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체 |
| `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` | 홈 화면에 추가할 때 쓰는 이름과 아이콘 |
| `sw.js` | 오프라인에서도 열리도록 파일을 저장해 두는 서비스 워커 |
| `.gitignore` | 백업과 내보낸 CSV를 실수로 올리지 않도록 막는 설정 |

## 올리고 쓰는 방법 (GitHub Pages)

1. 이 폴더의 파일을 모두 저장소 맨 위에 올립니다. 하위 폴더에 넣지 마세요.
2. 저장소의 Settings → Pages에서 배포할 브랜치(main)와 폴더(/ root)를 고릅니다.
3. 잠시 뒤 `https://계정이름.github.io/저장소이름/` 주소에서 앱이 열립니다.
4. 휴대폰 브라우저로 그 주소를 열고, 공유 메뉴에서 "홈 화면에 추가"를 하세요. 처음 한 번은 인터넷이 연결된 곳에서 열어야 합니다.

파일을 직접 열어도(`index.html`을 브라우저로 열기) 기본 기능은 되지만, 홈 화면 앱과 오프라인 저장은 주소(https)로 열 때만 됩니다.

## 저장과 백업

- 기록은 사용하는 기기의 브라우저 저장소(localStorage와 IndexedDB)에만 저장됩니다. 서버로 보내지 않습니다.
- 브라우저 데이터를 지우거나 다른 기기·다른 브라우저로 열면 기록이 보이지 않습니다.
- 탐조를 종료하면 백업 파일(`birdlog-backup-….json`)이 내려받아집니다. 이 파일에는 탐조 기록이 들어 있으니 공개 저장소에 올리지 마세요.
- 다른 기기에서 편집할 때는 내보내기 탭의 "불러오기"에서 백업 파일을 고릅니다.

## 알려진 한계

- eBird 가져오기용 CSV의 열 순서는 eBird 도움말의 레코드 형식 견본과 처음 한 번 비교해서 확인해야 합니다.
- 위치 좌표는 자동으로 불러오지 않습니다. 장소의 좌표는 설정에서 직접 입력하거나, eBird 가져오기 화면에서 지도로 고릅니다.
- 사진과 녹음은 다루지 않습니다.
- 서비스 워커와 홈 화면 추가는 브라우저와 기기에 따라 동작이 다를 수 있고, 아직 실제 기기에서 확인하지 못했습니다.
