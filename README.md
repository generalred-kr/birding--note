# 탐조 기록장

휴대폰에서 탐조 중에 눌러서 기록하고, 집에서 eBird에 올릴 수 있는 파일로 내보내는 한 파일짜리 웹 앱입니다. 개인용으로 만든 비공식 도구이며 eBird, Cornell Lab of Ornithology와 관련이 없습니다.

## 기능

- **탐조 기록**: 날짜와 시각, 장소, 탐조 방식(이동·정점·우연), 관찰자 수, 동행, 이동 거리, 모두 기록 여부. 날씨, 기온, 바람, 서식지, 물 상태, 장비, 방해 요인, 목적, 이동 수단은 "더보기"에 있습니다.
- **종 기록**: 한국 조류 598종을 이름, 초성(예: ㅈㅂ), 영문명, 학명, 과 이름으로 검색합니다. 개체수는 숫자로 직접 입력하고, 행동, 확실도, 소리만 들음, 확인 필요, 희귀 표시를 남깁니다.
- **특징**: 새 그림에서 부위별 색(머리, 부리, 등, 배, 날개, 허리, 꼬리, 다리)과 무늬 12가지를 팔레트로 고릅니다. 그림을 누르면 확대됩니다.
- **eBird 링크**: 종마다 eBird 종 페이지로 가는 버튼이 있습니다.
- **내보내기**: eBird 가져오기용 CSV(레코드 형식), 사진·녹음 시각표 CSV, 백업 파일.
- **자동 저장과 불러오기**: 1분마다 그리고 기록을 바꿀 때마다 브라우저에 저장하고, 자동 저장본이나 백업 파일을 합치거나 바꿔서 불러올 수 있습니다.

## 사용

`index.html` 하나로 동작하며 서버나 빌드 과정이 없습니다. 브라우저로 열면 됩니다. 기록은 사용하는 기기의 브라우저 저장소(localStorage와 IndexedDB)에만 저장되므로, 브라우저 데이터를 지우면 사라질 수 있습니다. 탐조를 마칠 때마다 백업 파일을 저장하세요.

## 데이터 출처

- 한국 조류 목록: `2025_Bird_Korea` 목록(598종)
- 영문명과 종 코드: eBird/Clements Checklist v2025

원본 자료의 사용 조건을 확인한 뒤 저장소를 공개하세요.

## 알려진 한계

- eBird 가져오기용 CSV의 열 순서는 eBird 도움말의 레코드 형식 견본과 처음 한 번 비교해서 확인해야 합니다.
- 사진 찍기, 녹음, 현재 위치 불러오기는 지원하지 않습니다. 사진과 녹음은 휴대폰 기본 앱으로 찍고, 앱에서는 찍은 시각만 남깁니다.
